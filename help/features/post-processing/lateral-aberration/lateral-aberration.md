# Lateral aberration

![](../../../assets/v12_post_aberration.jpg)

Simulates chromatic aberration by shifting color channels outward from the center of the image, reproducing the color fringing visible at the edges of real camera lenses.

| <b>Parameter</b> | <b>Description</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Amount</b> | Controls the intensity of the color fringing effect. Higher values produce more pronounced channel separation toward the edges. |
| <b>Radius</b> | Controls the size of the unaffected center region. Smaller values push the aberration effect closer to the center, affecting more of the image. |
| <b>Softness</b> | Controls the smoothness of the transition between the corrected center and the aberrated edges. |
| <b>Ratio</b> | Sets the aspect ratio of the affected region. A value of 1 creates a circular shape; values greater than 1 create a wider, elliptical pattern. |
| <b>Center X</b> | Horizontal position of the optical center from which the aberration radiates. |
| <b>Center Y</b> | Vertical position of the optical center from which the aberration radiates. |
| <b>Achromatic aberrations</b> | Switches the aberration colors from standard rainbow to green/violet tones. |
