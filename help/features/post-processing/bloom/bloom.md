# Bloom

![](../../../assets/v12_post_bloom.jpg)

Creates a soft glow around bright areas of the scene. Simulates how light scatters in a bright aura.

| <b>Parameter</b> | <b>Description</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Amount</b> | Controls the intensity of the bloom effect. Higher values produce a more pronounced glow around bright areas. |
| <b>Threshold</b> | Sets the minimum brightness level required to trigger bloom. Only pixels brighter than this value will glow. A threshold of 1.0 means only pixels brighter than screen white will bloom. |
| <b>Falloff</b> | Determines how far the bloom spreads from bright areas. Lower values create a more compact glow, while higher values spread the effect across a larger area. |
