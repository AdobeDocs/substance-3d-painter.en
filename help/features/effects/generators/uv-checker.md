# UV Checker

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>In:</strong> uv, border, random</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>The UV Checker generator applies a grid-like checker pattern to your model so you can easily spot UV problems such as stretching, uneven scale, or distortion. <br><br>The UV Checker generator is generally used directly on a fill layer to see UV distortions.</td>
  </tr>
</table>

## Parameters

<table>
  <tr>
    <th>Parameter name</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>Set the seed value used to generate the dirt texture. <br><ul><li>Click Random to switch to another random seed.</li><li>Click the pencil to see the current seed value, and enter a specific value if desired.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Checker Color Mode</strong></td>
    <td>Select how colors are assigned:<br><ul><li><strong>Uniform</strong>: Applies the same color across the texture set.</li><li><strong>Random</strong>: Applies a random color to each UV island.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Checker Color</strong></td>
    <td>Set the color of the checker pattern.</td>
  </tr>
  <tr>
    <td><strong>Checker Grid Tile</strong></td>
    <td>Adjust the size of the checker pattern.</td>
  </tr>
  <tr>
    <td><strong>Checker Grid Opacity</strong></td>
    <td>Adjust the opacity of the grid. With 0 opacity, only a checker texture is visible, without a grid.</td>
  </tr>
  <tr>
    <td><strong>UV Borders Color</strong></td>
    <td>Set the color of the UV borders.</td>
  </tr>
  <tr>
    <td><strong>UV Borders Width</strong></td>
    <td>Adjust the width of the UV borders.</td>
  </tr>
</table>
