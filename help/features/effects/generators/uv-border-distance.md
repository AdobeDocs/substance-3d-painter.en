# UV Border Distance

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_border_distance.png" alt=""/><br><strong>In:</strong> mesh, uv, distance</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>The UV Border Distance generator creates a grayscale mask on the borders of the UV islands, letting you easily add various effects that follow the borders of your UVs.<br><br>The UV Border Distance generator outputs a monochrome (black-and-white) texture. As a result, it’s useful for generating a mask that highlights areas near your UV borders.</td>
  </tr>

## Parameters

| Parameter name | Description |
| --- | --- |
| **Invert** | Invert the generator output. |
| **Balance** | Adjust the balance of the effect, shifting the midpoint toward black or white like a brightness control. |
| **Contrast** | Adjust the contrast/falloff of the effect. |
| **Smoothness** | Adjust the roundness of the effect. This is most visible when a low **Smoothness** value is used. |
| **Distance** | Adjust how far the effect extends away from UV borders. |
