# Auto Stitcher

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_auto_stitcher.png" alt=""/><br><strong>In:</strong> stitch, stitches</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>The Auto Stitcher generator automatically creates a stitching effect along procedurally generated paths. These paths can be generated based on UV seams, Curvature, or a custom input map.<br><br>The Auto Stitcher generator outputs a monochrome (black and white) texture. As a result, it’s useful for generating masks to apply stitching effects.<br><br>To use the Curvature Mask Mode, a baked curvature map is required. <a href="../../../baking/baking.md">Learn more about baking here</a>.</td>
  </tr>
</table>

## Inputs

<table>
  <tr>
    <th>Input name</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>Curvature</strong> Grayscale</td>
    <td>Select how to generate the stitching paths:<br><ul><li>UV Mask generates the paths along UV seams.</li><li>Curvature generates paths near hard edges.</li><li>Custom input allows you to control where paths are generated by using a map.</li></ul><br><br><br><br><br><br>When using Custom input, paths will be generated in high contrast areas.</td>
  </tr>
  <tr>
    <td><strong>Custom Input</strong> Grayscale</td>
    <td>Use a custom texture or an anchor point.</td>
  </tr>
</table>

## Parameters

<table>
  <tr>
    <th>Parameter name</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>Mask Mode</strong></td>
    <td>Determines the Mask mode.<br><ul><li>UV Mask: Masks based on UV islands.</li><li>Curvature: Masks based on the Curvature map.</li><li>Custom Input: Masks based on a Custom Input texture.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Path Smoothness</strong></td>
    <td>Softens the path where the stitches are applied.</td>
  </tr>
  <tr>
    <td><strong>Path Position</strong></td>
    <td>Offsets the path position.</td>
  </tr>
  <tr>
    <td><strong>Stitch Size</strong></td>
    <td>Adjusts the scale of the stitches.</td>
  </tr>
  <tr>
    <td><strong>Stitch Width</strong></td>
    <td>Adjusts the width of the stitches.</td>
  </tr>
  <tr>
    <td><strong>Stitch Length</strong></td>
    <td>Adjusts the length of the stitches.</td>
  </tr>
  <tr>
    <td><strong>Stitch Roundness</strong></td>
    <td>Adjusts the shape roundness of the stitches.</td>
  </tr>
  <tr>
    <td><strong>Jitter</strong></td>
    <td>Adjusts the jitter in stitches flow direction.</td>
  </tr>
</table>
