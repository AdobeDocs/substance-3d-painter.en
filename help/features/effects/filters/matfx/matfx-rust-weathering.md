## Description

The MatFX Rust Weathering filter creates rust buildup and weathering across a material.

It is used on texture layers or material stacks to add corrosion, drips, and aged weathering effects.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Blur Intensity:</b> | Adjusts the strength of the blur effect. |
| <b>Blur Wrap:</b> | Toggles blur wrap on or off. When blur wrap is on it samples pixels from the opposite side of the texture. |
| <b>Rust Spreading:</b> | Adjust rust spreading. |
| <b>Spreading Smoothness:</b> | Adjust spreading smoothness. |
| <b>Varnish Damage Scale:</b> | Adjust varnish damage scale. |
| <b>Drips Intensity:</b> | Adjust drips intensity. |
| <b>Drips Samples Amount:</b> | Adjust drips samples amount. |
| <b>Drips Smoothness:</b> | Adjust drips smoothness. |

### Blending

| Parameter name | Description |
| --- | --- |
| <b>Normal Intensity:</b> | Adjust the normal map blend intensity. |
| <b>Ambient Occlusion Intensity:</b> | Adjust the AO map blend intensity. |
| <b>Height Intensity:</b> | Adjust the height map blend intensity. |

**Metallic Roughness**

| Parameter name | Description |
| --- | --- |
| <b>Base Color Intensity:</b> | Adjust base color intensity. |
| <b>Roughness Intensity:</b> | Adjust the roughness map blend intensity. |
| <b>Metallic Intensity:</b> | Adjust the metallic map blend intensity. |
