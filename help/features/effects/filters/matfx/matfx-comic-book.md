<td width="100.00%" style="border: 0;" valign="top">

## Description

The MatFX Comic Book filter stylizes materials with a comic-book-inspired look.

It is used on texture layers to create a graphic, illustrated rendering style with simplified shading and bold visual treatment.

## Inputs

| Input name | Description |
| --- | --- |
| <b>Ambient Occlusion:</b> Grayscale | Use the baked ambient occlusion map. |
| <b>Curvature:</b> Grayscale | Use the baked curvature map. |

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Input Type:</b> | Select the input type used by the effect. |
| <b>Input Contrast:</b> | Adjust the contrast of the input. |
| <b>Input Luminosity:</b> | Adjust the luminosity of the input. |
| <b>Color Intensity:</b> | Adjust the intensity of the color treatment. |
| <b>Border Opacity:</b> | Adjust the opacity of the borders. |
| <b>Border Tolerance:</b> | Adjust the border detection tolerance. |
| <b>Border Smoothness:</b> | Adjust the smoothness of the borders. |
| <b>Paint Intensity:</b> | Adjust the intensity of the paint effect. |
| <b>Warp:</b> | Adjust the warp effect. |
| <b>Sharpness:</b> | Adjust the sharpness of the result. |
| <b>Output Contrast:</b> | Adjust the contrast of the output. |
| <b>Output Luminosity:</b> | Adjust the luminosity of the output. |
