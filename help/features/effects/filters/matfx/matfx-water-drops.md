# MatFX Water Drops

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![MatFX Water Drops icon](./Resources/icon_matfx_water_drops.png  "MatFX Water Drops")

<b>In:</b> Effects/blur, grayscale

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

The MatFX Water Drops filter creates water droplet and runoff effects on a material.

It is used on texture layers or material stacks to add droplets, directional streaking, and wet-surface variation.

</td>
</tr>

## Inputs

| Input name | Description |
| --- | --- |
| <b>Ambient Occlusion:</b> Grayscale | Use the baked ambient occlusion map. |
| <b>World Space Normals:</b> Color | Use the baked world space normals map. |
| <b>Position:</b> Color | Use the baked position map. |

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Drops Amount:</b> | Adjust the amount of water drops. |
| <b>Drops Scale X:</b> | Adjust the X scale of the drops. |
| <b>Drops Scale Y:</b> | Adjust the Y scale of the drops. |
| <b>Drops Scale Random:</b> | Adjust the amount of random scale variation in the drops. |
| <b>Drops Direction Intensity:</b> | Adjust the directional intensity of the drops. |

### Position

| Parameter name | Description |
| --- | --- |
| <b>Influence X:</b> | Adjust the X influence of the position input. |
| <b>Influence Y:</b> | Adjust the Y influence of the position input. |
| <b>Influence Z:</b> | Adjust the Z influence of the position input. |

### Water Accumulation

| Parameter name | Description |
| --- | --- |
| <b>Intensity:</b> | Adjust the intensity of the water accumulation. |
| <b>Spread:</b> | Adjust the spread of the water accumulation. |
| <b>AO Based Intensity:</b> | Adjust how much ambient occlusion affects the water accumulation. |

### World Space

| Parameter name | Description |
| --- | --- |
| <b>Masking Intensity:</b> | Adjust the intensity of the world-space masking. |
| <b>Top Intensity:</b> | Adjust the intensity of drops on upward-facing areas. |
| <b>Bottom Intensity:</b> | Adjust the intensity of drops on downward-facing areas. |
| <b>Front Intensity:</b> | Adjust the intensity of drops on front-facing areas. |
| <b>Back Intensity:</b> | Adjust the intensity of drops on back-facing areas. |
| <b>Right Intensity:</b> | Adjust the intensity of drops on right-facing areas. |
| <b>Left Intensity:</b> | Adjust the intensity of drops on left-facing areas. |

### Material

| Parameter name | Description |
| --- | --- |
| <b>Drops Base Color Warp Intensity:</b> | Adjust the warp intensity applied to the base color under the drops. |
| <b>Drops Rotation Vector Map Multiplier:</b> | Adjust the multiplier applied to the drop rotation vector map. |
| <b>Drops Height Intensity:</b> | Adjust the intensity of the drop height effect. |
| <b>Drops Roughness:</b> | Adjust the roughness of the drops. |
| <b>Drops Roughness Blending:</b> | Adjust how the drop roughness blends with the material. |
| <b>Drops Metallic:</b> | Adjust the metallic value of the drops. |
| <b>Drops Metallic Blending:</b> | Adjust how the drop metallic value blends with the material. |
| <b>Normal Intensity:</b> | Adjust the intensity of the normal effect. |
