<td width="100.00%" style="border: 0;" valign="top">

## Description

The MatFX Watercolor filter stylizes the source with a watercolor look.

It is used on texture layers to create watercolor bleeding, paper interaction, and soft painted edges.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Paint Opacity:</b> | Adjust the opacity of the paint. |
| <b>Paper Absorption:</b> | Adjust how strongly the paper absorbs the paint. |
| <b>Accumulation Type:</b> | Select the accumulation method. |
| <b>Borders Spread:</b> | Adjust the spread of the paint borders. |
| <b>Borders Density:</b> | Adjust the density of the paint borders. |
| <b>Show cross paint edges:</b> | Toggle display of cross-paint edges. |
| <b>Hide Paper:</b> | Toggle visibility of the paper texture. |
| <b>Custom Paper:</b> | Toggle use of a custom paper texture. |
