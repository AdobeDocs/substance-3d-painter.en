## Description

The MatFX Shut Line filter creates panel-line or seam details on a material.

It is used on texture layers or material stacks to add shut lines, embossed seams, and supporting height and color detail.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Cavity Width:</b> | Adjust the width of the cavity. |
| <b>Slope Intensity:</b> | Adjust the intensity of the slope effect. |
| <b>Emboss Strength:</b> | Adjust the strength of the embossing. |
| <b>Height Intensity:</b> | Adjust the intensity of the height effect. |

### Material

| Parameter name | Description |
| --- | --- |
| <b>Line Color:</b> | Adjust the line color. |
| <b>Source Material Opacity:</b> | Adjust the opacity of the source material. |
