## Description

The MatFX Oil Paint filter stylizes the source with an oil-paint appearance.

It is used on texture layers to create painterly strokes, color variation, and surface detail inspired by oil paint.

## Parameters

**Presets** are available and can quickly update multiple other parameters in the Filter to act as a starting point.

>[!NOTE]
>
> When a preset is selected, it will set all parameters to a preset value - if you have made changes to the filter that you don't want to lose, it may be worth creating a duplicate of the filter and toggling visibility before trying presets.

| Parameter name | Description |
| --- | --- |
| <b>Input Type:</b> | Select the input type used by the effect. |
| <b>Effect Intensity:</b> | Adjust the overall intensity of the effect. |
| <b>Fine Details:</b> | Adjust the amount of fine detail preserved in the result. |
| <b>Sharpness:</b> | Adjust the sharpness of the result. |
| <b>Roughness:</b> | Adjust the roughness value. |
| <b>Roughness Variation:</b> | Adjust roughness variation across the result. |
| <b>Roughness Details:</b> | Adjust how much detail affects the roughness. |
| <b>Normal Intensity:</b> | Adjust the intensity of the normal effect. |
| <b>Normal Strokes Direction Influence:</b> | Adjust how strongly stroke direction affects the normal result. |
