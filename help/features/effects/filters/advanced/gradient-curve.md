## Description

The Gradient Curve filter remaps values through a customizable gradient curve.

It is used on a texture layer or inside a mask (black and white output) to remap grayscale values with preset curve shapes.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Preset:</b> | Select the curve preset. |
| <b>Invert:</b> | Toggle inversion of the result. |
| <b>Balance:</b> | Adjust the balance of the result between black and white, similar to a brightness adjustment. |
| <b>Contrast:</b> | Adjust the contrast or falloff of the result. |
