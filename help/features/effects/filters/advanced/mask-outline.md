## Description

The Mask Outline filter creates an outline from the edges of a mask.

It is used on a texture layer or inside a mask (black and white output) to generate an inside, outside, or double outline around a masked shape.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Mask Position:</b> | Select whether the outline appears outside, inside, or on both sides of the mask edge. |
| <b>Start From Black:</b> | Toggle whether the outline starts from black. This effectively acts as a kind of inversion toggle. |
| <b>Threshold:</b> | Adjust the threshold used to detect the mask edge. |
| <b>Width:</b> | Adjust the width of the outline. |
| <b>Blur:</b> | Adjust the blur applied to the outline. |
| <b>Curve Shape:</b> | Adjust the shape of the outline falloff. |
