## Description

The Bevel filter adds a beveled edge to grayscale shapes and masks.

It is used on a texture layer or inside a mask (black and white output) to create beveled relief along the edges of a shape.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Bevel Wrap:</b> | Toggle wrapping so the bevel tiles horizontally and vertically. |
| <b>Distance:</b> | Adjust the bevel size. |
| <b>Corner Type:</b> | Select whether bevel corners are rounded or angular. |
| <b>Smoothing:</b> | Adjust the amount of smoothing applied to the bevel. Without any smoothing, curved bevels can have visible striations due to aliasing along the curve. |
| <b>Blur Mode:</b> | Select whether the bevel uses uniform or non-uniform blur. Non-uniform blur focuses the blur effect on the bevelled areas, which can help to maintain detail, but uniform blur is more consistent. |
