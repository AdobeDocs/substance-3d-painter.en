## Description

The Pixelate filter converts an input into big blocks to simulate a pixelated look.

It is used on a texture layer (color) or a mask to pixelate full materials, noises, masks, shapes etc.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Pixels Amount:</b> | Adjust the number of pixels which has the side effect of changing the pixel size. More pixels means smaller pixels. |
| <b>Apply To Alpha:</b> | Toggle whether the filter also modifies the Alpha channel. |
