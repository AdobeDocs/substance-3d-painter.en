## Description

The Posterize filter reduces the number of colors or tones in an image, creating a stepped look with more pronounced areas and edges.

It is used on texture layers or masks (color or grayscale) to create stylized, graphic looks by simplifying colors. This is often useful for posters, illustrations, or reducing detail for artistic effect.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Colors Amount:</b> | Adjust the number of color steps. |
| <b>Apply to Alpha:</b> | Toggle whether the Alpha channel is also affected by this filter. |
