## Description

The Histogram Scan filter remaps the contrast and brightness of an input grayscale image.

It is used either directly on a fill layer or on a mask (black and white output) to adjust the contrast and brightness.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Position:</b> | Adjust the histogram position. |
| <b>Contrast:</b> | Adjust the contrast/falloff of the result. |
| <b>Invert Position:</b> | Toggle inversion of the position. At very high or very low Position values this effectively inverts the output. |
