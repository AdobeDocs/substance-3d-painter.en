## Description

The Glow filter creates an outer glow around the visible parts of the input.

It is used on a texture layer or inside a mask (black and white output) to add a soft or precise glow around shapes and materials.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Used on a Mask:</b> | Toggle whether the glow is used on a mask. |
| <b>Mode:</b> | Select whether the glow uses Soft or Precise mode. |
| <b>Width:</b> | Adjust the width of the glow. |
| <b>Spread:</b> | Adjust the spread of the glow. |
| <b>Opacity:</b> | Adjust the opacity of the glow. |
| <b>Color:</b> | Adjust the glow color. |
