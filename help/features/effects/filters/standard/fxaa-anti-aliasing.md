## Description

The FXAA (Anti-Aliasing) filter applies an anti aliasing filter based on the FXAA algorithm. You can use this to fix jagged, pixelated edges on shapes.

It is used on a texture layer or a mask (black and white output) layer to make sharp contrasted outlines less jagged.
