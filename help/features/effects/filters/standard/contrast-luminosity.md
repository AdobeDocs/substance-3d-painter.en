## Description

The Contrast Luminosity filter is a simple contrast and luminosity (brightness) adjustment.

It is used either directly on a fill layer or on a mask (black and white output) to tweak contrast and luminosity (brightness).

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Contrast:</b> | Adjust the contrast/falloff of the result. |
| <b>Luminosity:</b> | Adjust the luminosity. |
