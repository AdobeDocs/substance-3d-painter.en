## Description

The Mirror filter is a symmetry filter to copy a part of the input.

It is used on a texture layer (color) or a mask to mirror complete materials, masks, shapes etc. based on the mirror axis.

</td>
</tr>
</table>

>[!NOTE]
>
> The mirror filter works in UV space, so it may be useful to open the 2D view in the **Viewport**.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Display Debug:</b> | Toggle display of the debug view. |
| <b>Mode:</b> | Select the mirror mode. |
| <b>Axis X Offset:</b> | Adjust the X-axis offset. |
| <b>Axis Y Offset:</b> | Adjust the Y-axis offset. |
| <b>Invert Axis X:</b> | Toggle inversion on the X axis. |
| <b>Invert Axis Y:</b> | Toggle inversion on the Y axis. |
| <b>Corner Type:</b> | Select how mirrored corners are handled. |
