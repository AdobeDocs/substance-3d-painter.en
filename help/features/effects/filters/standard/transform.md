## Description

The Transform filter is used to transform (scale, rotate, offset) a layer.

It is used on a texture layer or inside a mask (black and white output) to for example transform patterns, shapes etc.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Repeat mode:</b> | Select the repeat mode. |
| <b>Flip mode:</b> | Select the flip mode. |
| <b>Scaling X:</b> | Adjust the X scaling of the result. |
| <b>Scaling Y:</b> | Adjust the Y scaling of the result. |
| <b>Offset X:</b> | Adjust the X offset of the result. |
| <b>Offset Y:</b> | Adjust the Y offset of the result. |
| <b>Tile Safe Rotation:</b> | Toggle tile-safe rotation. |
| <b>Rotation:</b> | Adjust the rotation. |
| <b>Scaling:</b> | Adjust the overall scaling. |
| <b>Offset:</b> | Adjust the overall offset. |
