## Description

The HSL Perceptive filter adjusts the hue, saturation and lightness.

It is used on a texture layer (color) to make adjustments to hue, saturation, and lightness.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Mode:</b> | Select the HSL adjustment mode. **Perceptive** adjusts values based on how we perceive color, while **Regular** adjusts based on how the computer represents color internally. |
| <b>Hue:</b> | Adjust the hue. |
| <b>Saturation:</b> | Adjust the saturation. |
| <b>Lightness:</b> | Adjust the lightness. |
