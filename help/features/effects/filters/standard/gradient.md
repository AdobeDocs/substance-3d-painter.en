# Gradient

<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Gradient icon](./Resources/icon_gradient.png "Gradient")

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

The Gradient filter remaps the grayscale values in an image using a custom gradient.

It can be used to tweak the values of a grayscale image or to colorize grayscale input by mapping it to a custom gradient.

</td>
</tr>

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Display Gradient (Debug):</b> | Toggle display of the gradient debug view. |
| <b>Color Quantity:</b> | Adjust the number of colors used in the gradient. |
| <b>Blend Color in Linear:</b> | Toggle linear color blending. |
| <b>Color 1:</b> | Select the first color. |
| <b>Color 1 Position:</b> | Adjust the position of the first color. |
| <b>Color 2:</b> | Select the second color. |
| <b>Color 2 Position:</b> | Adjust the position of the second color. |
| <b>Color N:</b> | Select the Nth color. |
| <b>Color N Position:</b> | Adjust the position of the Nth color. |

<table>
