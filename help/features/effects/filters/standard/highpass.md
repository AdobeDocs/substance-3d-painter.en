## Description

The Highpass filter performs a highpass effect, similar to the Photoshop action with the same name. It is useful for removing large luminance differences in images, such as when cleaning textures for tiling.

It is used on a texture layer or a mask layer to remove large luminance differences.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Color Space:</b> | Select the color space used by the filter. |
| <b>Radius:</b> | Adjust the highpass radius. |
| <b>Apply To Alpha:</b> | Toggle whether the filter affects the Alpha channel. |
