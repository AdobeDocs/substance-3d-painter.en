## Description

The Drop Shadow filter creates a drop shadow.

It is used on a paint layer to create drop shadows based on your painted strokes.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Angle:</b> | Adjust the shadow angle. |
| <b>Distance:</b> | Adjust the shadow distance. |
| <b>Size:</b> | Adjust the shadow size. |
| <b>Spread:</b> | Adjust the spread of the shadow. |
| <b>Opacity:</b> | Adjust the shadow opacity. |
| <b>Color:</b> | Adjust the shadow color. |
