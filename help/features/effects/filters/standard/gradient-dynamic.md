## Description

The Gradient Dynamic filter remaps the grayscale values in an image to a gradient defined by colors placed at specific points along the gradient.

It is used on a texture layer or inside a mask (black and white output) to remap grayscale values with a gradient sampled from another image.

| Input name | Description |

| <b>Gradient Source:</b> Color | Use a custom color map or an anchor point. |

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Gradient Orientation:</b> | Select whether the gradient source is sampled horizontally or vertically. |
| <b>Gradient Input Position:</b> | Adjust the position sampled from the gradient input. |
