## Description

The Grayscale Conversion filter converts a channel/color image to grayscale by weighing the luminance of each color channel. You have a lot of options to tweak the conversion.

It is used on a texture layer or a mask layer to convert the channels to grayscale or to convert a color image to grayscale and use it as mask.

<a name="parameters"></a>

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Channel Input:</b> | Select the channel input used for the conversion. |
| <b>Invert:</b> | Toggle inversion of the result. |
| <b>Balance:</b> | Adjust the balance of the result between black and white, similar to a brightness adjustment. |
| <b>Contrast:</b> | Adjust the contrast/falloff of the result. |
| <b>Mode:</b> | Select the grayscale conversion mode. |
| <b>Red:</b> | Adjust the weighting for the Red channel. This weighting is used to calculate the grayscale result. |
| <b>Green:</b> | Adjust the weighting for the Green channel. This weighting is used to calculate the grayscale result. |
| <b>Blue:</b> | Adjust the weighting for the Blue channel. This weighting is used to calculate the grayscale result. |
| <b>Alpha:</b> | Adjust the weighting for the Alpha channel. This weighting is used to calculate the grayscale result. |
