## Description

The Color Balance filter makes subtle changes to highlights, midtones, and shadows.

It is used on a fill layer to make subtle color adjustments.

## Parameters

### Highlights

| Parameter name | Description |
| --- | --- |
| **Cyan <-> Red:** | Shift the color towards cyan or red. |
| **Magenta <-> Green:** | Shift the color towards magenta or green. |
| **Yellow <-> Blue:** | Shift the color towards yellow or blue. |
