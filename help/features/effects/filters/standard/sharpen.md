## Description

The Sharpen filter performs a sharpening operation on selected channels. It is useful for applying that final touch of crispness to a channel/mask.

It is used on texture layers or masks (color or grayscale). It can also be added to a paint layer above the rest of the layer stack, then set to passthrough and applied to all channels so everything below receives the sharpening effect. Avoid pushing it too far, as it is usually best kept subtle.
