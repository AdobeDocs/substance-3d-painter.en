## Description

The MatFinish Rough filter is part of a metal finish collection and is used to create a rough metal effect.

It is used on a fill layer. Adjust the color, roughness, metallic, and other properties of the base fill layer, then add the filter for the final surface treatment.

## Inputs

| Input name | Description |
| --- | --- |
| <b>Custom Grunge:</b> Grayscale | Use a custom grunge texture or an anchor point. |
| <b>Position:</b> Color | Use the baked Position map. |
| <b>World Space Normals:</b> Color | Use the baked World Space Normals map. |

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Seed:</b> | Assign a random value to create a different variation without changing the overall settings. |
| <b>Scale:</b> | Adjust the overall scale of the finish. |
| <b>Scale Grunge:</b> | Adjust the scale of the grunge pattern. |
| <b>Brushing Intensity:</b> | Adjust the intensity of the brushing effect. |
| <b>Brushing Warp:</b> | Adjust the amount of warping applied to the brushing. |
| <b>Use Custom Flake:</b> | Toggle use of the custom flake input. |
| <b>Triplanar Mapping:</b> | Toggle triplanar mapping. |
| <b>Use Custom Grunge:</b> | Toggle use of a custom grunge texture. |
