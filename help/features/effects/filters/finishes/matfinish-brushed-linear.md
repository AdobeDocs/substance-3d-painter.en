## Description

The MatFinish Brushed Linear filter is part of a metal finish collection and is used to create a linear brushed metal effect.

It is used on a fill layer. Adjust the color, roughness, metallic, and other properties of the base fill layer, then add the filter for the final surface treatment.

## Parameters

| Parameter name | Description |
| --- | --- |
| <b>Seed:</b> | Assign a random value to create a different variation without changing the overall settings. |
| <b>Scale:</b> | Adjust the overall scale of the finish. |
| <b>Brushing Intensity:</b> | Adjust the intensity of the brushing effect. |
| <b>Length:</b> | Adjust the length of the brushed streaks. |
| <b>Rotation:</b> | Adjust the rotation of the brushed pattern. |
