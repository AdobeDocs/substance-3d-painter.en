# Baking mode

**Baking mode** provides access to all of the tools and parameters you need to create great, high-quality bakes.

To access **Baking mode**, click the (baked) Croissant button at the top right of the Viewport. Alternatively, use [keyboard shortcut ](../interface/settings/shortcuts.md)**F8**, or select **Mode &gt; Bake Mesh Maps**

![](../assets/baking/mode_select_buttons.png)

Baking mode changes the UI layout and makes different panels available specifically for baking mesh maps.

## Interface

The Baking Mode interface is, by default, divided between the [**Viewport**](../interface/viewport/viewport.md) and the panel area.

### Viewport

The [**Viewport**](../interface/viewport/viewport.md) behaves the same as in **Painting mode**. You can navigate with the same controls, and use the **Channel dropdown** to change which channels are displayed.

The **Baking mode Viewport** differs from **Painting mode** in two ways:

* At the top left of the Viewport, you can find the [**Baking visualization settings panel**](baking-visualization-settings.md).
* At the bottom of the viewport, you can find buttons to **Bake** the currently selected mesh maps, or return to **Painting mode**.

### Baking mode Panels

There are 4 panels exclusive to Baking mode:

* [**Mesh map bakers**](../interface/baking-panels/mesh-map-bakers.md): Select which mesh maps are baked.
* [**Common settings**](../interface/baking-panels/common-mesh-map-settings.md): Adjust baking settings common to all mesh maps.
* [**Mesh map settings panel**](../interface/baking-panels/mesh-map-settings.md): Adjust baking settings for the selected mesh map.
* [**Baking log**](../interface/baking-panels/baking-log.md): View the results of bakes and diagnose issues.

>[!NOTE]
>
> See [**Mesh map settings**](mesh-map-settings.md) for a full list of options available in the **Common settings** and **Mesh map settings panels**.
