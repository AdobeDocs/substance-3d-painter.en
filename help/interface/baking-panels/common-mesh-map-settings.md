# Common settings panel

In [**Baking mode**](../../baking/baking.md), the **Common settings panel** displays parameters that are relevant to all mesh maps.

>[!NOTE]
>
> Settings in the Common settings panel apply to all mesh maps when baking. There isn’t a way to override common settings for a specific mesh map.
>
> If, for example, you want to bake Normal maps at a higher resolution, you will need to:
>
> 1. **Bake** your maps at the lower resolution.
> 1. **Uncheck** other mesh maps so that only Normal is **checked**.
> 1. Change the Common settings **Output size**.
> 1. **Bake** the Normal map.

A full list of the mesh map settings available in the **Common settings** and the [**Mesh map settings panels**](mesh-map-settings.md) is available [in the baking section of the documentation](../../baking/mesh-map-settings.md).
