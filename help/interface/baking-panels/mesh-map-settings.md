# Mesh map settings panel

In [**Baking mode**](../../baking/baking.md), the **Mesh map settings panel** displays parameters for the currently selected mesh map type in the **Mesh map bakers panel**.

A full list of the mesh map settings available in the [**Common settings**](common-mesh-map-settings.md) and the **Mesh map settings panels** is available [in the baking section of the documentation](../../baking/mesh-map-settings.md).
