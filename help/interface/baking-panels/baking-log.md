# Baking log

The **Baking log panel** shows technical output related to baking. The panel contains three tabs:

* **Baking process**: See the status of ongoing baking tasks or the most recent baking run.
* **High poly parameters**: Find details about high poly files used in your project.
* **Matching by name**: When **High poly parameters &gt; Match** is set to **By mesh name**, this tab shows information about how assets have been matched up.

>[!TIP]
>
> Information about how to match assets by name is available in [the Bakers documentation](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/features/matching-by-name).
