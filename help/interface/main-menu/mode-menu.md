# Mode menu

![](../../assets/image2018-5-28-16-58-24.png)

From the Mode menu, you can switch between different interfaces to work on different tasks. Each Mode has a dedicated purpose and interface that cannot be accessed from other modes.

| Action | Description |
| --- | --- |
| **Bake mesh maps** | Use this mode to create utility maps like normals, world-space normals, AO, and ID maps, by baking from high-poly to low-poly, or just using the project mesh itself. |
| **Painting** | Where you’ll spend most of your time in Painter, Painting mode is where you can access the layer stack and materials, and paint directly on your 3D models. |
| **Rendering (Iray)** | Switch to Iray render mode. Iray is a non-realtime renderer which can create high quality renders. For more information see the dedicated page: [Iray Renderer](../../features/iray-renderer/iray-renderer.md). |
